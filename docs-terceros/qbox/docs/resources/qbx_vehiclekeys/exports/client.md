# Client Exports

*Documentation for client-side exports in the qbx_vehiclekeys resource. These exports provide functionality for checking and managing vehicle key ownership within the Qbox framework.*

## HasKeys

Returns whether the player has keys to the given vehicle entity

```lua
exports.qbx_vehiclekeys:HasKeys(vehicle)
```

- vehicle: `number`
