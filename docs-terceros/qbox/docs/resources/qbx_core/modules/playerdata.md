# playerdata

*Documentation for the playerdata module in the qbx_core resource. This module provides functionality for managing and updating player data through the QBX.PlayerData global variable, available on the client side.*

Adds a `QBX.PlayerData` global and keeps it updated.

## Installation

Add `@qbx_core/modules/playerdata.lua` to `client_scripts` in your fxmanifest.
