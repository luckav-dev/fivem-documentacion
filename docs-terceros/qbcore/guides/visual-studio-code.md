# 📝 Visual Studio Code

*A free, lightweight, text editor with many extension options!*

## Download

* Visit the [Visual Studio Code](https://code.visualstudio.com/) website and download the program

> **Advertencia:** Make sure you check the "Open with code" boxes!

## Fonts

### Fira Code

> **Nota:** Download file, double click the ttf files and install the font

> **Archivo:** [FiraCode.zip](https://github.com/qbcore-framework/qb-docs/blob/930c12ec4f60dfbba60253571f1a58980129516d/.gitbook/assets/FiraCode.zip)

> **Consejo:** File -> Preferences -> Settings -> Font Family -> Fira Code

![](../imagenes/firacodeexample.png)

### JetBrains Mono

> **Nota:** Download file, double click the ttf files you want and install the font

> **Archivo:** [JetBrainsMono-2.242.zip](https://github.com/qbcore-framework/qb-docs/blob/930c12ec4f60dfbba60253571f1a58980129516d/.gitbook/assets/JetBrainsMono-2.242.zip)

> **Consejo:** File -> Preferences -> Settings -> Font Family -> JetBrains Mono

![](../imagenes/jetbrainsfont.png)

## GitHub Integration

> **Peligro:** Must have [git](https://git-scm.com/downloads) installed!

> **Nota:** There is some configuring to do with these extensions but most of it is just signing into your GitHub account and exploring the "source control" tab on the left!
