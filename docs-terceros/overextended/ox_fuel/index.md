# Ox Fuel

**Enlaces del recurso:** [GitHub](https://github.com/overextended/ox_fuel) · [Descargar](https://github.com/overextended/ox_fuel/releases/latest/download/ox_fuel.zip)

A simple fuel resource meant to replace LegacyFuel or serve as a showcase for using petrol cans as an item.

## Installation

### 1. Install all resource dependencies.

- [ox_lib](../ox_lib/index.md)
- [ox_inventory](../ox_inventory/index.md)

### 2. Download a release or clone the source code.

- Download the [latest release](https://github.com/overextended/ox_fuel/releases/latest).

```bash
git clone https://github.com/overextended/ox_fuel.git
```

### 3. Install optional dependencies.

These resources aren't required but provide additional functionality.

- [ox_target](../ox_target/index.md)
